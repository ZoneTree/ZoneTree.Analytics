# Performance

Use query plans and representative measurements to decide what to aggregate, index, or tune. Start with the records a report actually reads.

## Measured at scale

The [5M-event query benchmark](./query-benchmarks/query-benchmarks.mdx) records **33 ms median** for all six annual overview reports, with comparisons enabled. It includes filtered reports, p95 timings, query plans, and the raw samples from the running dashboard.

## Recommended investigation

Read [query planning](./rollups/rollups.mdx), choose [index paths](./secondary-indexes/secondary-indexes.mdx) where appropriate, and measure the result with [benchmarking](./benchmarking/benchmarking.mdx).
