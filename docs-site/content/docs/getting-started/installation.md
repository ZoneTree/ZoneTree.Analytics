# Installation

Choose the packages for your application and prepare a persistent data directory.

## Choose your packages

`ZoneTree.Analytics` provides the embedded engine. `ZoneTree.Analytics.AspNetCore` adds host registration, tracking middleware, browser tracking, and reporting endpoints.

## Prepare your application

The library targets .NET 8, 9, and 10. The core engine can run in a web application, service, worker, or console application.

## Choose a data directory

Keep analytics data on persistent storage and assign one engine to each directory. The engine owns the directory for its lifetime.

## Choose your next step

Start with direct event tracking, integrate an ASP.NET Core host, or run the included dashboard application.
