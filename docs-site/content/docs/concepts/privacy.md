# Privacy and identity

Understand how event collection, visitor identity, and stored data fit together.

## Visitor identification

The built-in model uses hashed visitor identifiers and daily rotation. IP addresses and user agents support enrichment without being stored as raw fields.

## Data minimization

Choose which dimensions, values, and URL information your application permits. Custom event fields should follow the same collection policy as standard web fields.

## Collection policy

Privacy options, event filters, client-event rules, and host integration each control a different part of collection. Configure them together.

## Data lifecycle

Retention limits how long data remains available. Visitor erasure has its own storage requirements and should be planned before collecting data.
