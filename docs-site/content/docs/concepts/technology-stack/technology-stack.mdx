# Technology stack

ZoneTree.Analytics is a .NET library with embedded storage. Its included dashboard combines an ASP.NET Core reporting host with a static interface generated by PureStack and made interactive with Regor.

## Library and reporting host

| Technology | Role |
| --- | --- |
| .NET | Runs collection, enrichment, aggregation, and queries in the application process |
| [ZoneTree](https://zonetree.dev/) | Provides ordered, persistent storage and write-ahead logging for event history, sessions, rollups, and indexes |
| ASP.NET Core | Hosts request and browser tracking, reporting endpoints, and the dashboard server |

The core library supports .NET 8, 9, and 10. ASP.NET Core integration is provided by a separate package; the included dashboard server uses .NET 10.

## Dashboard and documentation

| Technology | Role |
| --- | --- |
| [PureStack](https://purestack.studio/) | Generates static pages from MDX and provides shared layouts, themes, navigation, and UI components |
| [Regor](https://regor.purestack.studio/) | Binds dashboard state to HTML and SVG for reports, filters, forms, and charts |
| TypeScript | Defines page behavior, components, and typed styles |

Each dashboard page owns a Regor application. The generated files supply the interface; the reporting API supplies live data. PureStack and Regor are used by the included UI, rather than required by applications using the core .NET library.
