# Event and report model

Understand events, dimensions, values, visitors, sessions, and sites as one analytics model.

## Events, dimensions, and values

An event has a name and timestamp. Dimensions describe categories such as page, source, or plan; numeric values describe measurements such as revenue or duration.

## Visitors and sessions

Visitor identity enables unique counts and behavioral analysis. Session tracking adds visit-level context used by bounce rate, duration, and entry and exit reports.

## Sites

Site identifiers separate events and query results within one engine. Applications decide how requests and tenants map to sites.

## Reports and general queries

Web reports provide a consistent website vocabulary. General queries select metrics, grouping dimensions, filters, and time intervals from the same underlying data.
