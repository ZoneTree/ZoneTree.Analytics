## Choose the right package

`ZoneTree.Analytics` provides tracking, storage, queries, and typed web reports. `ZoneTree.Analytics.AspNetCore` adds dependency injection, request and browser tracking, and reporting endpoints.

The dashboard is a separate application built on those packages. Its host settings are not the core library defaults.

## Build a useful report

Once collection is working, choose a workflow close to your application:

- **Website:** [Traffic, acquisition, and engagement](./guides/web-reports/web-reports.mdx).
- **Product:** [Purchases, revenue, and checkout completion](./guides/product-analytics/product-analytics.mdx).
- **Service or worker:** [Volume, errors, and latency](./guides/telemetry/telemetry.mdx).

Each guide connects the recorded fields to the questions the report answers. Use the [query reference](./reference/query-model/query-model.mdx) when you need the exact contracts.
