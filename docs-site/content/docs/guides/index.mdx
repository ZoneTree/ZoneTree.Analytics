# Practical guides

Follow a workflow for collecting activity, building a report, or analyzing behavior. Examples assume an engine already open for your application's lifetime.

## Choose a report path

| What you want to understand | Start here |
| --- | --- |
| Traffic, content, and acquisition | [Web reports](./web-reports/web-reports.mdx) |
| Customers, purchases, and revenue | [Product analytics](./product-analytics/product-analytics.mdx) |
| Request or job volume, errors, and latency | [Service and worker telemetry](./telemetry/telemetry.mdx) |
| Behavior across several actions | [Segments and funnels](./segments-and-funnels/segments-and-funnels.mdx) |
| A report with your own metrics and categories | [Querying and time series](./querying/querying.mdx) |
