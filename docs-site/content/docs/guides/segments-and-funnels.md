# Segments and funnels

Analyze behavior across events rather than treating each event independently.

## Define a behavioral segment

Select visitors or sessions based on actions such as viewing a page or completing a purchase. Apply the resulting membership to reports.

## Define a funnel

Choose ordered steps, identity scope, and a conversion window. Interpret completion and drop-off according to those choices.

## Understand event history requirements

Segments and funnels depend on event-level history. Raw-event retention therefore limits the historical behavior available for analysis.

## Design useful comparisons

Keep the site, cohort, time range, and identity model consistent when comparing funnels or segmented reports.
