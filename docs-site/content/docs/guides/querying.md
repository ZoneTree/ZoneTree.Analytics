# Querying and time series

Compose custom analytics from metrics, dimensions, filters, and time buckets.

## Build a query

Choose the event, site, range, metrics, grouping dimensions, and filters. Order and limit results to match the report you need.

## Work with numeric metrics

Combine counts and distinct counts with sums, distributions, conditional metrics, and formulas. Some aggregates require optional rollup configuration.

## Analyze change over time

Use calendar or custom intervals, comparisons, gap filling, and window calculations to turn aggregates into time-series reports.

## Interpret the result

Read rows, totals, and the execution plan together. Distinguish filtering source events from filtering aggregated results.
