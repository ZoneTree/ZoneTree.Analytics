# Web reports

Build website reports with consistent visitor, page, session, and conversion metrics.

## Traffic overview

Summaries and time series describe visitors, page views, sessions, engagement, and comparison periods.

## Pages, acquisition, and audience

Page reports and dimension breakdowns answer where traffic goes, where it comes from, and how people browse.

## Goals and bot traffic

Custom events provide goal and conversion reports. Bot traffic follows configured collection rules and has its own reporting context.

## Read reports consistently

Apply the same site, date range, filters, and comparisons across related reports. Some session metrics only apply to suitable breakdown dimensions.
