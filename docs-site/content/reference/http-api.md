# HTTP API reference

Organize the browser-tracking and reporting contracts exposed by ASP.NET Core.

## Tracker endpoints

Cover the script and event endpoint under the configured tracker prefix, client event format, payload limits, and accepted event rules.

## Web reporting routes

Group summary, time-series, page, dimension, goal, bot, and other web report routes by the question they answer.

## General query routes

Cover custom analytics and funnel requests, request and response models, and serialization of ranges, filters, and metrics.

## Authorization and limits

Cover site authorization, host authentication, concurrency limits, response bounds, cancellation, and error responses.

## Application-specific endpoints

The dashboard adds connection settings and Development-only sample-data controls. Identify these separately from the reusable library reporting API.
